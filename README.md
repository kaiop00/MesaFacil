# 🍽️ MenuWeb – Sistema Web de Autoatendimento para Restaurantes

**MenuWeb** é uma aplicação web responsiva que oferece autoatendimento completo para restaurantes. O sistema permite que clientes acessem o cardápio, façam pedidos, acompanhem o status, solicitem atendimento e realizem pagamentos diretamente de seus dispositivos móveis, sem a necessidade de instalar aplicativos.

## 📲 Como Funciona

1. O cliente escaneia um **QR Code** disponível na mesa.
2. É direcionado ao **cardápio digital personalizado**, acessado via navegador.
3. Pode realizar pedidos, acompanhar o preparo e solicitar a conta.
4. O restaurante recebe os pedidos em tempo real no painel do sistema.
5. O restaurante tem todo o controle diário, mensal, anual de vendas, estoque, acesso de funcionários.

## ⚙️ Funcionalidades Principais

- ✅ Acesso via QR Code, sem necessidade de app
- 📋 Visualização do cardápio digital com imagens e categorias
- 📝 Pedidos com observações e envio em tempo real
- 🔄 Acompanhamento do status do pedido
- 💳 Solicitação de pagamento ao garçom direto pelo sistema
- ✋ Solicitação de atendimento via sistema
- 🧑‍🍳 Painel de gerenciamento para operadores do restaurante
- 📈 Relatórios de vendas, pedidos e avaliações
- 🌐 Suporte a múltiplos idiomas
- 🎨 Personalização com logotipo e identidade visual

## 🧠 Benefícios

- Aumenta a autonomia e conforto do cliente
- Reduz o tempo de espera e erros no atendimento
- Facilita a gestão de pedidos e mesas
- Evita filas e a necessidade de comandas físicas
- Escalável para múltiplos estabelecimentos (modelo SaaS)

## 🛠️ Tecnologias Utilizadas

- **Frontend**: React.js
- **Backend**: Node.js
- **Banco de Dados**: Firebase
- **Comunicação em Tempo Real**: WebSocket (Socket.IO)
- **Hospedagem**: AWS, Vercel ou Azure
- **Pagamentos**: atendimento presencial com garçom e integrações via parceiros (em planejamento)
- **Segurança**: OAuth 2.0, JWT, TLS 1.3
- **DevOps**: Docker, GitHub Actions
